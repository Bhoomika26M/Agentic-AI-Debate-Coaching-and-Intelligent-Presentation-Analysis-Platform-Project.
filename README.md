# 🎙️ Agentic AI Debate Coach & Presentation Analysis Platform

An AI-powered platform that coaches debate, critical thinking, and public speaking.
Built with React + Vite, FastAPI, PostgreSQL, and Google Gemini.

## Prerequisites (Windows)

| Tool | Version |
|---|---|
| Python | 3.10 – 3.12 |
| Node.js | 18+ (20 recommended) |
| PostgreSQL | 14+ |
| Git | latest |
| Gemini API Key | Free tier from Google AI Studio |
